# Asteria downloads

This repository holds the installer payloads for [Asteria Japanese Input](https://github.com/aruiki/Asteria-Japanese-IME).

**You don't need to download anything here.** To install Asteria, download `Asteria-Setup.exe` from the [main repository's latest release](https://github.com/aruiki/Asteria-Japanese-IME/releases/latest). It fetches the files it needs from this repository and checks each one before installing it.

| Release | Contents |
| :--- | :--- |
| `v<version>` | `Asteria64.msi` (core) and `AsteriaCuda64.msi` (NVIDIA CUDA add-on, downloaded only on PCs with a supported NVIDIA driver) |
